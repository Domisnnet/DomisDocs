# 📝 Créditos & Reconhecimentos

| Atribuição | Responsável / Recurso | Descrição |
| :--- | :--- | :--- |
| **Engenharia & Documentação** | **DomisDev** | Criação, arquitetura técnica, testes práticos, organização do conteúdo e padronização visual de todo o material. |
| **Infraestrutura de Hosting** | **Google Firebase** | CDN global, certificado SSL automático, cache inteligente, hospedagem escalável e análise de performance. |
| **Framework Front-end** | **Angular** | Plataforma de desenvolvimento da aplicação de exemplo utilizada como referência no guia. |
| **Motor de Documentação** | **VitePress** | Gerador de site estático ultrarrápido que transforma o conteúdo Markdown em documentação profissional navegável. |
| **Ferramenta de Linha de Comando** | **Firebase CLI** | Interface oficial para automação de deploy e gestão de projetos Firebase. |
| **Ícones e Badges** | **Shields.io** | Geração dinâmica de badges visuais para status, versões e links rápidos. |
