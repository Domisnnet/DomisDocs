# 🎯 Objetivo

Este repositório serve como **referência técnica definitiva** para o fluxo de deploy de aplicações Angular 20 no Firebase Hosting. O guia documenta de forma completa:

### ✅ O que você vai dominar
- Instalação e configuração do Firebase CLI
- Autenticação da conta Google e associação ao projeto Firebase
- Geração de build de produção do Angular
- Localização correta do `index.html` gerado pelo build
- Configuração detalhada do `firebase.json` (pasta pública, rewrites, ignores)
- Teste local com o emulador do Firebase Hosting
- Deploy em produção
- Configuração de rotas para SPA Angular (rewrites)
- Troubleshooting de erros comuns e soluções validadas
- Boas práticas de estrutura, segurança e automação

### 📌 Resultado Final
Ao seguir este guia, você será capaz de:
> **Publicar qualquer aplicação Angular no Firebase Hosting de forma segura, rápida, automatizada e seguindo padrões profissionais de engenharia de front-end.**
