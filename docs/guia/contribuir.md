# 🤝 Como Contribuir

Siga os passos abaixo para fortalecer este projeto e sugerir melhorias:

| Fase | Ação | Link / Comando |
| :---: | :--- | :--- |
| **01** | **Fork** | [![Fork](https://img.shields.io/badge/-Fazer%20Fork-blue?style=flat-square&logo=github)](https://github.com/Domisnnet/DomisDocs/fork) |
| **02** | **Branch** | `git checkout -b feature/MinhaMelhoria` |
| **03** | **Commit** | `git commit -m 'feat: atualização na seção de troubleshooting'` |
| **04** | **Push** | `git push origin feature/MinhaMelhoria` |
| **05** | **PR** | [![Abrir PR](https://img.shields.io/badge/-Abrir%20PR-green?style=flat-square&logo=git)](https://github.com/Domisnnet/DomisDocs/compare)

### 🐛 Encontrou um problema?
Se algo não estiver funcionando como esperado, não hesite em abrir um chamado:

[![Issues Abertas](https://img.shields.io/github/issues/Domisnnet/DomisDocs?style=flat-square&color=red&logo=github)](https://github.com/Domisnnet/DomisDocs/issues)
[![Report Bug](https://img.shields.io/badge/Reportar-Erro-critical?style=flat-square&logo=github)](https://github.com/Domisnnet/DomisDocs/issues/new)

### 📌 Diretrizes de Contribuição
- Mantenha o estilo visual consistente com o restante do guia (badges, formatação, tabelas)
- Atualize a documentação sempre que alterar um comando, configuração ou versão
- Teste qualquer alteração no emulador local antes de enviar o PR
- Mantenha commits claros e descritivos seguindo padrões convencionais
