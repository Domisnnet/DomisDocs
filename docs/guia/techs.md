# ⚙️ Tecnologias Utilizadas

| Camada | Tecnologias | Descrição |
| :--- | :--- | :--- |
| **Core** | ![Angular](https://img.shields.io/badge/Angular%2020-DD0031?style=flat-square&logo=angular&logoColor=white) | Framework front-end — aplicação de exemplo para deploy. Arquitetura moderna com suporte a componentes standalone. |
| **Hosting** | ![Firebase](https://img.shields.io/badge/Firebase%20Hosting-FFCA28?style=flat-square&logo=firebase&logoColor=black) | Hospedagem estática global com CDN, certificado SSL automático, cache inteligente e escalabilidade sem gestão de servidores. |
| **Ferramentas** | ![Firebase CLI](https://img.shields.io/badge/Firebase%20CLI-FFCA28?style=flat-square&logo=firebase&logoColor=black) | Interface de linha de comando para autenticação, inicialização, configuração e deploy de projetos Firebase. |
| **Documentação** | ![VitePress](https://img.shields.io/badge/VitePress-646CFF?style=flat-square&logo=vitepress&logoColor=white) | Gerador de site estático para documentação técnica profissional. Transforma Markdown em site navegável ultrarrápido. |
| **Runtime** | ![Node.js](https://img.shields.io/badge/Node.js-20.19%2B-339933?style=flat-square&logo=node.js&logoColor=white) | Ambiente de execução JavaScript necessário para Angular CLI, Firebase CLI e build de documentação. |

### 📋 Requisitos Mínimos
Antes de iniciar, certifique-se de ter instalado:

| Requisito | Versão Recomendada |
|---|---|
| Node.js | 20.19+ |
| npm | Compatível com Node.js |
| Angular CLI | 20.x |
| Firebase CLI | 15.x+ |
| Navegador Web | Chrome, Edge, Firefox ou Safari atualizados |
| Conta Google | Para autenticação no Firebase |

Verifique as instalações com:
```bash
node --version
npm --version
ng version
firebase --version
