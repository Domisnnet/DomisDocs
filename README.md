<h2 id="sobre-o-projeto">1. 🚀 DomisDocs — Plataforma de Documentação Técnica DomisDev 🚀</h2>

![Status](https://img.shields.io/badge/Status-Online-brightgreen?style=flat-square)
![VitePress](https://img.shields.io/badge/VitePress-646CFF?style=flat-square&logo=vitepress&logoColor=white)
![Firebase](https://img.shields.io/badge/Firebase%20Hosting-FFCA28?style=flat-square&logo=firebase&logoColor=black)
[![Licença MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://github.com/Domisnnet/DomisDocs/blob/main/LICENSE)

> **DomisDocs** é a plataforma oficial de documentação técnica profissional do **DomisDev**. Um sistema reutilizável, escalável e elegante para criar, publicar e manter guias, referências e tutoriais de qualquer tecnologia, framework ou ferramenta de desenvolvimento.

> Este repositório contém como exemplo prático o guia completo de **Deploy Angular 20 no Firebase Hosting**, mas a estrutura serve como base para **qualquer projeto futuro**.

<h2 id="objetivo">4. 🎯 Objetivo</h2>

O **DomisDocs** foi criado para ser:
- 📖 **Uma plataforma reutilizável** para documentar qualquer tecnologia
- 🎨 **Um padrão visual consistente** para todos os projetos do DomisDev
- 🚀 **Um sistema escalável** — adicionar novos guias é tão simples quanto criar um novo arquivo `.md`
- 💼 **Um diferencial profissional** — entregando documentação técnica de altíssimo nível em cada projeto

> O guia de **Deploy Angular 20 no Firebase Hosting** serve como exemplo prático e conteúdo inicial da plataforma.
